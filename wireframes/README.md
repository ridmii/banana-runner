# Wireframes - Banana Runner Game

This folder contains wireframes and design mockups for the Banana Runner game.

## Screen Structure

### Authentication Screens
- `auth-login.md` - Login page wireframe
- `auth-register.md` - Registration page wireframe

### Game Screens
- `main-menu.md` - Main menu with level badges and navigation
- `game-world.md` - 3D game environment and UI overlay
- `leaderboard.md` - Ranking and scoring display
- `profile.md` - User profile and achievements

### UI Components
- `navbar.md` - Top navigation bar
- `ui-overlay.md` - In-game UI elements

## Wireframe Format

Each wireframe file contains:
- Screen layout description
- Component hierarchy
- User interaction flows
- Key design notes
